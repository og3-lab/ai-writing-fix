# ai-writing-fix: AI に書かせた文章から、AI っぽさを抜く

生成 AI に書かせたブログ・資料・メール・SNS 投稿などから、AI っぽさを抜くための手順です。チャットに貼る依頼文と、Claude Code のスキルの2つの形で使えます。

利用条件: 改変・業務利用は可。再配布は不可。

## 何をするか

AI っぽさの多くは、言葉の選び方より、素材が無いまま型どおりに埋めることと、同じことを言い直すことから出ます。そこで次の4つをします。

1. 書かせる前に、AI からあなたへ質問させる（日時や数字のほか、体験なら印象に残った場面と感じたこと、資料なら一番伝えたいことと自分の提案）
2. 読み手にチャットで聞かれた返事として書かせる
3. 同じことの言い直しを消す
4. 書いたときのやり取りを持たない別の AI に、2周読ませて直す

依頼文だけ（チャットで書く→新しいチャットで2周目）で13ジャンルを1本ずつ書かせ、別の編集者役の AI（Claude Opus）に判定させると、13本すべてで AI っぽい箇所が1件以下でした（書かせたのも判定したのも Claude。ChatGPT では測っていません）。

## 使い方

### チャットで使う（ChatGPT・Claude など）
`prompts/chat-prompt.md` の枠の中をコピーしてチャットに貼り、続けて直したい文章か「〜を書いて」を送ります。使い方の細かい手順はファイルの先頭にあります。

### Claude Code で使う

```
/plugin marketplace add og3-lab/ai-writing-fix
/plugin install ai-writing-fix@ai-writing-fix
```

「〜を書いて」「この文章の AI っぽさを直して」と頼むと、スキルが手順どおりに動きます。ジャンル別の物差し、言い直しを見つけるスクリプト、点検する編集者も一緒に入ります。スクリプトには Python 3 が要ります（無くても、言い直しを目で探す手順に切り替わります）。

チャットで使う場合は依頼文1枚だけで動きます。物差し13種とスクリプトは、Claude Code で使うときに効きます。

## 中身

| ファイル | 役目 |
|---|---|
| `prompts/chat-prompt.md` | チャットに貼る依頼文 |
| `skills/ai-writing-fix/SKILL.md` | Claude Code 用の手順（素材を聞く → 返事として書く → 重複を消す → 編集者に2周点検させる） |
| `skills/ai-writing-fix/references/genres/` | ジャンルごとの物差し13種と、全ジャンル共通の AI っぽい型の一覧（`00_共通.md`） |
| `skills/ai-writing-fix/scripts/find_repeats.py` | 同じことの言い直しを機械で見つけるスクリプト |
| `agents/ai-writing-editor.md` | 指摘だけを返す編集者（書いた本人とは別の目で読む） |
